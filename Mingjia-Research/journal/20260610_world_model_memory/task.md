# Task

Analyze the argument for a glass substrate system with:

- 73 TB/s aggregate all-to-all fabric bandwidth,
- effectively much larger local memory via dual/triple memory panels,
- target workloads: world models and long video generation.

Key question:

What can this architecture enable that current NVIDIA GPU systems cannot, while acknowledging that 73 TB/s is below current NVL72-class aggregate NVLink bandwidth?
